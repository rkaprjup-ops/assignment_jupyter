## Predictive Maintenance

Develop a machine learning model to predict whether an asset is likely to fail within the next 24
hours.
The model should help operations teams proactively schedule maintenance activities.

Expected Activities
● Data preprocessing
● Feature engineering
● Handling missing values
● Model selection
● Model training
● Model evaluation
● Error analysis

Suggested Algorithms
● Random Forest
● XGBoost
● LightGBM
● CatBoost
● Any appropriate approach

Evaluation Metrics
● Precision
● Recall
● F1 Score
● ROC-AUC

Explain
● Why the selected model was chosen.
● Important features driving predictions.
● Potential business impact.
