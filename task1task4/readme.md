## TASK 1
Exploratory Data Analysis (EDA)
Perform a detailed exploratory analysis on the telemetry data.
Your analysis should:
● Understand data distributions.
● Identify missing values and anomalies.
● Discover temporal patterns.
● Analyze asset behavior across sites.
● Compare performance across asset types.
● Identify factors influencing equipment failures.
● Identify factors affecting energy consumption.
Deliverables
Provide:
● Visualizations
● Statistical summaries
● Key observations
● Business insights

## Task 4
Anomaly Detection
Design an anomaly detection framework capable of identifying abnormal equipment behavior.
Examples include:
● Sudden power spikes
● Excessive vibration
● Sensor drift
● Abnormal temperature patterns
● Equipment degradation
Suggested Techniques
● Isolation Forest
● Autoencoders
● Statistical Thresholding
● Clustering
● Change Point Detection
Deliverables
● Anomaly detection methodology
● Visualizations
● Identified anomalies

● Business recommendations
